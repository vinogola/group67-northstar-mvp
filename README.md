# Northstar Support Deflection MVP
Group 67's MVP for Northstar Retail Co. — lets customers check order status and stock availability without opening a support ticket.
Live: https://group67-northstar-mvp.vercel.app
## Run locally
**Prerequisites:** Node.js
1. Install dependencies: `npm install`
2.Run the app: `npm run dev`
